# LegalEase ⚖️

LegalEase is an AI-powered legal document generator.

## Features

- Generate legal document drafts
- Employment Contract
- Non-Disclosure Agreement (NDA)
- Lease Agreement
- Edit generated documents
- Preview documents
- Download documents as TXT

## Purpose

This project is developed for educational and drafting purposes.
Generated documents should be reviewed by a qualified legal professional before use.

## Technology

- Python
- Streamlit
- FastAPI
- AI integration
- Python document processing
